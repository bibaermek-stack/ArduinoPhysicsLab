Google кіру неге істемейді

Қазіргі Client ID — Desktop қосымшаның клиенті. Ол тек localhost-қа рұқсат береді, интернеттегі сайтқа емес. Сондықтан Google redirect_uri_mismatch көрсетеді.

Сайт үшін жаңа клиент жасаңыз: түрі міндетті түрде Web application.

  1. Ашыңыз: Google Cloud → Credentials
  2. Create credentials → OAuth client ID
  3. Application type: Web application (Desktop / iOS / Android емес)
  4. Name: Arduino Physics Lab Web
  5. Authorized JavaScript origins — Add URI, дәл осыны қойыңыз:

{{ origin }}

Authorized redirect URIs — Add URI, дәл осыны қойыңыз (соңында / және жол жоқ):

{{ redirect_uri }}

  1. Create басыңыз. Жаңа Client ID мен Client secret көшіріңіз.
  2. Railway → жоба → Variables ішінде ауыстырыңыз:
    • GOOGLE_CLIENT_ID = жаңа Web Client ID
    • GOOGLE_CLIENT_SECRET = жаңа Web Client secret
    • APL_PUBLIC_BASE_URL = {{ origin }}
  3. Сақтаған соң Railway қайта іске қосылады. 1–2 минут күтіп, кіру бетінен Google-ды қайта басыңыз.

Ескі Desktop клиентті сайтқа қоюдың қажеті жоқ — ол ешқашан жұмыс істемейді.

Google-сыз кіру үшін email арқылы тіркеліңіз — бұл жол қазір істейді.
