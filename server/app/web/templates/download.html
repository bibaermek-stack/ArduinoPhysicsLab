Windows «вирус табылды» — бұл вирус емес

ArduinoPhysicsLab.exe қолтаңбасыз PyInstaller бумасы. Defender / SmartScreen оны жиі жалған қауіп деп белгілейді («Обнаружен вирус»). Файл GitHub Releases-тен шығады, зиянды код жоқ.

  1. Параметры Windows → Безопасность Windows → Защита от вирусов и угроз → Журнал защиты.
  2. ArduinoPhysicsLab.exe жолын табыңыз → Действия → Разрешить на устройстве.
  3. Егер файл Downloads-та қалса: оң батырма → Свойства → Разблокировать → ОК, сосын ашыңыз.

Кейде Defender файлды карантинге алады — жоғарыдағы «Разрешить» оны қайтарады. Содан кейін қайта жүктеудің қажеті жоқ.
